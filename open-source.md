# Open-source libraries

MK Plus is built with open-source projects; Settings → Acknowledgements in the app lists every one, with
what it does and its full licence.

Some of them are licensed under the GNU Lesser General Public License (LGPL). Each is included as a
separate dynamic framework, so it can be replaced with another build of the same library, and their
complete source for the versions in the current app is published here:

**[Source of the LGPL libraries](https://github.com/mkolakowski/mkplus-guide/releases/tag/lgpl-sources-ffmpegbuild-3.5.0-mk2)**

| Library | Version |
|---|---|
| FFmpeg | 8.1.3 |
| FFmpegBuild | 3.5.0-mk2 |
| libzvbi | 0.2.45 |

Each set of versions gets its own release, and the app's Acknowledgements link to the one it was built
with. Older releases stay up.
